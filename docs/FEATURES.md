# Features and provider differences

| Area | Included |
|---|---|
| Discovery | BBC/ITV/Channel 4/Channel 5/U catalogues; mixed Featured banner; merged genre categories; network headings/badges; landscape programme art and portrait posters where supplied. |
| Search | Cached title/synopsis search across providers, plus provider search where implemented; native keyboard/iPhone keyboard/dictation where the system supports them. |
| Library | Local saved programmes, Continue Watching, start over, remove from history and known next episodes. |
| Episodes | Latest season/year by default; genre/title-based newest-first soaps; chronological episode succession; paged episode lists and continuous category browsing. |
| Autoplay | Fifteen seconds after an episode ends; Cancel, Back and Play now; stops on dismissal, backgrounding, errors or an unknown successor; never schedules live streams. |
| Live | BBC, ITV, Channel 4 and Channel 5; approved Freeview-style order; regional extras; network filters; separate ITV/5 themed sections; programme thumbnails when available. |
| Top Shelf | Matching ordered native sections and direct launches for all supported live providers, including Channel 5. |
| BBC extras | Sixteen BBC One region choices, three BBC Two feeds, RED additional streams, event-dependent Red Button UHD, skip-intro/recap timings and compatible live subtitles. |
| Playback | AVKit controls, on-demand speed choices, bounded Info panel, guidance/runtime/date where supplied, received-resolution badges and native compatible subtitles. |
| UHD | Optional on-device TwinVine setup for compatible BBC 4K HLG HDR; cached UHD category in Browse; no UHD claim for the other providers. |
| Linking | Provider-site QR/code linking for ITV live, Channel 5 and U as required. Current Channel 4 route has no in-app linking flow. |
| Interface | Boxed Telly logo, RGB pulsing loading feedback respecting Reduce Motion, shared neutral styling and Home re-selection that returns from nested programme pages. |

Provider differences are part of the release, not hidden behind the general feature list. U live channels are not integrated. Channel 4 catch-up requests HD-capable FairPlay streams where offered; quality varies by programme and service response. ITV and U FHD, and supported Channel 5 FHD streams, have been confirmed on a physical Apple TV; some Channel 5 catch-up remains SD. BBC UHD needs a compatible episode/version, setup and display path. Subtitles/skip timings depend on provider metadata and the exact stream. Subscription-only playback, offline downloads, server-side history sync and App Store distribution are not included.

The newest autoplay, navigation and channel-grouping changes build and pass targeted logic checks; wider device testing is still welcome. See VALIDATION.md.
